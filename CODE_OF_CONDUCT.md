# Code of Conduct

## Our commitment

The NLX Music project aims to be a respectful, constructive space for people who participate in development, issue discussions, reviews, and documentation.

## Expected behavior

- Be respectful and considerate.
- Critique ideas and code, not people.
- Explain disagreements calmly and focus on evidence.
- Share reproducible bug reports and useful technical details.
- Respect privacy and do not post another person's personal information.
- Be honest about testing, functionality, attribution, and project status.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Deliberately misleading contributors or users.
- Submitting fabricated test results, fake reviews, or unsupported claims that NLX Music is “#1” or “Top 1.”
- Spamming discussions or repeatedly disrupting project work.

## Reporting concerns

If you experience or observe unacceptable behavior, contact the project maintainer through the GitHub repository by opening an appropriate issue or using GitHub's available reporting tools. Do not include private or security-sensitive information in a public issue.

Reports will be reviewed as reasonably as possible. The maintainer may edit, close, or remove contributions that violate this code of conduct.

## Scope

This code applies to project spaces and interactions directly related to NLX Music, including repository issues, pull requests, and project discussions.
